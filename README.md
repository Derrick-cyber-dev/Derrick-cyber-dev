## Featured Project: LiberiaClinic

**Free digital patient records for rural clinics in Liberia, built for low connectivity.**

A multi-clinic patient records system designed for rural health facilities that still run on paper.

- **Patient registry and visit logging**: demographics, vitals, diagnoses, medications and follow-ups
- **Allergy alerts**: automatic warning before a visit for at-risk patients
- **Multi-clinic isolation**: each clinic sees only its own patients, with an administrator view across clinics
- **Two-factor authentication**: admin-issued access code plus Google Authenticator (TOTP)
- **Admin panel**: staff accounts, clinic management and access-code generation
- **PDF export**: complete patient record with visit history
- **Installable PWA**: runs on any Android phone, with cached pages for poor connections
- **Security hardening**: parameterised queries, input sanitisation, security headers, encrypted 2FA secrets

**Status:** version 1.0 is built and tested locally. A 90-day pilot across three Liberian counties
is being prepared. Offline data entry with background sync is planned for the next phase.
The source code is in a private repository and is available for technical review on request.
